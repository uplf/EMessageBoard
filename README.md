# 权益平台留言板小程序 (EMessageBoard)

本项目是一款基于 **微信小程序云开发 (WeChat Cloud Development)** 构建的闭环式诉求反馈与管理系统。它旨在连接普通用户、管理人员与职能部门，实现留言申请、任务指派、部门处理、进度跟踪的数字化管理。



## 🌟 核心特性

- **多角色权限体系**：支持普通用户、管理员、部门处理员等多种角色，根据登录身份动态展示功能菜单。
- **全生命周期管理**：涵盖留言的“提交 -> 审核 -> 派发 -> 处理 -> 回复 -> 办结”完整流程。
- **云开发架构**：无需自建服务器，利用微信云函数、云数据库和云存储实现高效后端逻辑。
- **现代化 UI**：基于 `ColorUI` 组件库开发，界面美观，交互流畅，适配各种移动端屏幕。

## 🛠 技术栈

- **前端框架**：原生微信小程序框架
- **后端支撑**：微信小程序云开发 (Cloud Functions, Cloud Database)
- **UI 组件库**：ColorUI
- **开发工具**：微信开发者工具 (WeChat DevTools)

## 🔄 业务流程说明

1.  **身份认证**：程序启动时通过 `getOpenid` 云函数识别用户，并在云数据库 `userinfo` 中查询匹配角色。
2.  **提交申请**：用户填写留言主题、内容及相关信息，数据存入云数据库。
3.  **任务流转**：
    - 管理员在后台查看未处理留言，根据内容指派给特定部门（`department_array`）。
    - 状态由“待处理”流转为“处理中”。
4.  **部门处理**：相关部门人员收到任务后进行反馈，并在 `solution` 和 `communicate` 字段中记录处理细节。
5.  **进度查看**：用户可实时在列表中看到自己留言的最新进度及最终解决方案。

## 🚀 快速开始

### 1. 克隆/下载项目
将本项目代码导入到 **微信开发者工具** 中。

### 2. 环境配置
- 点击开发者工具上方的“云开发”按钮，开通云服务。
- 在 `app.js` 中修改 `wx.cloud.init` 的 `env` 为您自己的云环境 ID：
  ```javascript
  wx.cloud.init({
    env: 'your-env-id',
    traceUser: true,
  })
  ```

### 3. 部署云函数
- 进入 `cloudfunctions` 目录。
- 依次右键点击每个云函数文件夹（如 `addMessage`），选择 **“上传并部署：所有文件”**。

### 4. 数据库准备
在云开发控制台中手动创建以下集合（Collections）：
- `userinfo`: 存储用户信息（openid, role, name 等）。
- `messages`: 存储留言主表数据。

## 📝 开发者备注

- **角色定义**：在 `app.js` 的 `globalData.LOGIN_STATUS` 中定义了角色代码（1-用户, 2-管理员, 3-维护员等）。
- **样式定制**：项目深度依赖 `colorui/main.wxss` 和 `colorui/icon.wxss`，修改样式时请优先参考组件库文档。
